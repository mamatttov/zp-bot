# zp-bot
[![tests](https://github.com/mamatttov/zp-bot/actions/workflows/tests.yml/badge.svg)](https://github.com/mamatttov/zp-bot/actions/workflows/tests.yml)

Telegram-бот для уведомления сотрудников о выплате заработной платы.

После проведения выплат в бухгалтерии сотрудники часто обращаются с одними и теми же вопросами: сколько начислено, что удержано, почему сумма на руки отличается от прошлого месяца. zp-bot снимает эту нагрузку. Бот получает данные из расчётной ведомости 1С, автоматически уведомляет каждого сотрудника о его выплате и даёт доступ к истории начислений.

Проект разработан на Python и SQLite в учебных целях. Все данные в репозитории вымышленные.

## Возможности

* Автоматическое уведомление сотрудника о новой выплате
* Детализация выплаты: начислено, Соцфонд, подоходный налог, прочие удержания, сумма на руки
* История за последние 6 месяцев с динамикой к предыдущему месяцу
* Итоги года: общая сумма, среднемесячный доход, лучший месяц
* Загрузка расчётной ведомости из 1С (.xlsx) с предварительным просмотром
* Привязка сотрудника по одноразовому коду

Пример уведомления:

```
💰 Новая выплата: зарплата за октябрь 2026
Дата: 05.11.2026

Начислено: 60 000,00 сом
Соцфонд: −6 000,00 сом
Подоходный налог: −5 400,00 сом
Прочие удержания: −600,00 сом
На руки: 48 000,00 сом
```

| Команда | Назначение |
|---|---|
| `/link КОД` | привязка Telegram к сотруднику |
| `/last` | последняя выплата |
| `/history` | история за 6 месяцев |
| `/year` | итоги года |
| `/help` | справка |

## Ключевое решение: данные без пересчёта

Бот не рассчитывает налоги и удержания самостоятельно. Все суммы берутся из расчётной ведомости 1С в неизменном виде. Это исключает расхождения между данными бухгалтерии и тем, что видит сотрудник, и избавляет от необходимости поддерживать в коде ставки и правила расчёта.

## Архитектура

```
Ведомость 1С (.xlsx) ──▶ vedomost_1c.py ──▶ SQLite: payments (notified_at = NULL)
                                                     │
                   notifier.py, раз в 30 секунд ◀────┘ выборка неотправленных
                                │
                                ▼
               Telegram: «💰 Новая выплата…» ──▶ notified_at = время отправки
```

Факт отправки фиксируется в базе. Перезапуск бота не приводит к повторным уведомлениям, а при сетевой ошибке уведомление будет отправлено на следующей итерации.

Импорт идемпотентен: повторная загрузка той же ведомости не создаёт дублей.

## Безопасность

* Параметризованные SQL-запросы исключают SQL-инъекции.
* Бот работает только в личных чатах, что исключает утечку данных в групповые чаты.
* Коды привязки одноразовые и генерируются через `secrets`. Перебор ограничен пятью неверными попытками в час.
* Пользовательские данные экранируются перед выводом (`html.escape`).
* Токен, база данных и реальные ведомости исключены из репозитория через `.gitignore`.

## Технологии

* **Python 3.10+**, **aiogram 3** (асинхронная обработка сообщений, фоновая задача рассылки)
* **SQLite**: внешние ключи, ограничения `CHECK`, частичный индекс, представление `VIEW`, оконная функция `LAG`, `CTE`, `JOIN`
* **openpyxl**: разбор Excel-файлов 1С по заголовкам столбцов и уровням группировки строк
* **Docker** и **docker compose** для развёртывания, **pytest** и **GitHub Actions** для автоматической проверки

## Установка и запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate            # Windows
   # source .venv/bin/activate       # Linux / macOS
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
4. Загрузите демонстрационную ведомость:
   ```bash
   python -m zp_bot.vedomost_1c sample/ведомость.xlsx --check
   python -m zp_bot.vedomost_1c sample/ведомость.xlsx --date 2026-11-05
   ```
   Первая команда показывает содержимое без записи в базу, вторая выполняет импорт и выводит коды привязки.
5. Запустите бота и отправьте ему `/link КОД`:
   ```bash
   python -m zp_bot
   ```

## Запуск в Docker

Нужен только Docker, Python ставить не требуется.

1. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
2. Запустите:
   ```bash
   docker compose up -d --build
   ```

Токен передаётся в контейнер из `.env` и в образ не попадает. База лежит в папке `data/` на хосте и сохраняется при пересборке образа. При сбое или перезагрузке сервера контейнер поднимается сам. Процесс в контейнере работает от непривилегированного пользователя.

| Задача | Команда |
|---|---|
| Логи | `docker compose logs -f bot` |
| Импорт ведомости | `docker compose exec bot python -m zp_bot.vedomost_1c sample/ведомость.xlsx --date 2026-11-05` |
| Коды привязки | `docker compose exec bot python -m zp_bot.codes` |
| Остановить | `docker compose down` |

## Настройки

Все настройки задаются в файле `.env`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | обязательна | токен бота |
| `DB_PATH` | `data/zp.db` | путь к базе SQLite |
| `NOTIFY_INTERVAL` | `30` | как часто искать новые выплаты, в секундах |
| `LOG_LEVEL` | `INFO` | подробность логов: `DEBUG`, `INFO`, `WARNING` |

## Логи

Логи пишутся в стандартный вывод, в Docker их собирает `docker compose logs`. В лог попадают запуск и остановка бота и отправленные уведомления. Суммы выплат, ФИО и коды привязки в лог не пишутся.

```
2026-11-11 10:15:02 INFO    zp_bot.__main__: Бот запущен, база data/zp.db, проверка выплат каждые 30 с
2026-11-11 10:16:32 INFO    zp_bot.notifier: Отправлено уведомлений: 1
```

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

23 теста проверяют работу с базой, оформление сообщений, импорт из CSV и из ведомости 1С, рассылку уведомлений. Telegram в тестах заменён фейковым объектом, поэтому токен и интернет не нужны. GitHub Actions запускает тесты при каждом push.

## Администрирование

| Задача | Команда |
|---|---|
| Предпросмотр ведомости | `python -m zp_bot.vedomost_1c файл.xlsx --check` |
| Импорт ведомости | `python -m zp_bot.vedomost_1c файл.xlsx --date ГГГГ-ММ-ДД` |
| Список сотрудников и кодов | `python -m zp_bot.codes` |
| Перевыпуск кода сотруднику | `python -m zp_bot.codes 0002` |
| Импорт сотрудников из CSV | `python -m zp_bot.importer sotrudniki файл.csv` |
| Импорт выплат из CSV | `python -m zp_bot.importer vyplaty файл.csv` |

Формат CSV с выплатами (разделитель `;`):

```
tab_no;period;kind;gross;social_fund;income_tax;other_withheld;paid_at
0002;2026-10;зарплата;54000;5400;4860;0;2026-11-05
```
